บทที่ 4

เลือกโน้ตบุคสำหรับทำงานกับ AI

ไม่ใช่แค่สเปคดีที่สุด แต่คือเครื่องที่เหมาะกับวิธีทำงานของคนที่ใช้ AI เป็นเครื่องมือหลักในชีวิต

เทคโนโลยี · อุปกรณ์  ·  sirichokbook

เริ่มอ่าน

สารบัญ

iคนทำงานกับ AI ต้องการอะไรจากเครื่อง iiMac หรือ Windows — ตอบให้ชัดก่อน iiiตัวเลือกที่แนะนำในงบ 20,000–40,000 ivตั้งค่าเครื่องใหม่ให้พร้อมทำงานกับ AI vบทสรุป: สเปคไม่ใช่คำตอบ วิธีใช้ต่างหากที่สำคัญ

คำถามว่า "ควรซื้อโน้ตบุครุ่นไหน" มักได้คำตอบที่มุ่งไปที่สเปคเป็นหลัก RAM เท่าไหร่ กราฟิกการ์ดรุ่นอะไร ความจุเท่าไหร่

แต่สำหรับคนที่ต้องการใช้ AI เป็นเครื่องมือหลักในการทำงาน คำถามที่สำคัญกว่านั้นคือ เครื่องนี้จะช่วยให้การทำงานกับ AI ราบลื่นแค่ไหน และมันจะยังตอบโจทย์ได้ในอีก 3-4 ปีข้างหน้าไหม

· · ·
i

คนทำงานกับ AI ต้องการอะไรจากเครื่อง

ก่อนดูตัวเลือก ต้องเข้าใจก่อนว่าการทำงานกับ AI ในชีวิตประจำวันต้องการอะไรจากเครื่องบ้าง เพราะมันต่างจากการเล่นเกมหรือตัดต่อวิดีโออย่างมาก

สำคัญมาก
แบตอยู่ได้นาน
การใช้ Claude Code และ Terminal ต่อเนื่องทั้งวันโดยไม่มีปลั๊กต้องการแบตที่เชื่อถือได้จริง ไม่ใช่แบตที่บอกว่า 10 ชั่วโมงแต่ได้จริง 6
สำคัญมาก
Terminal ใช้งานได้ลื่น
Claude Code ทำงานผ่าน Terminal การที่ Terminal ตั้งค่าง่ายและใช้งานได้ทันทีช่วยประหยัดเวลาและลดความหงุดหงิดได้มาก
สำคัญปานกลาง
จอสบายตา
อ่านข้อความและโค้ดนานๆ จอที่ดีลด eye strain ได้มาก ความสว่างและ color accuracy สำคัญกว่าขนาด
สำคัญปานกลาง
น้ำหนักเบา
ถ้าพกทุกวันน้ำหนักสะสมกลายเป็นเรื่องใหญ่ ต่างกัน 300-400 กรัมฟังดูน้อย แต่รู้สึกได้ชัดหลังพกไปสัปดาห์หนึ่ง

สิ่งที่ไม่จำเป็นสำหรับการทำงานกับ AI ในชีวิตประจำวันคือ กราฟิกการ์ดแยก เพราะ Claude Code และ AI tools ทำงานบน Cloud ทั้งหมด ไม่ต้องการ GPU ในเครื่อง และ RAM เกิน 16GB เพราะงานส่วนใหญ่เป็นการพิมพ์ คิด และสั่งงาน AI ไม่ใช่การ render หรือประมวลผลหนักๆ

· · ·
ii

Mac หรือ Windows — ตอบให้ชัดก่อน

นี่คือคำถามที่ต้องตอบก่อนทุกอย่าง และคำตอบไม่ได้ขึ้นอยู่กับความชอบส่วนตัว แต่ขึ้นอยู่กับโปรแกรมที่ต้องใช้ในงาน

ถ้างานต้องการโปรแกรม Windows เฉพาะ — เลือก Windows ถ้าไม่มีข้อจำกัดนั้น — Mac ตอบโจทย์การทำงานกับ AI ได้ดีกว่า

เหตุผลที่ Mac ได้เปรียบสำหรับงาน AI โดยเฉพาะ คือTerminal บน Mac ใช้ได้ทันทีโดยไม่ต้องตั้งค่าอะไรเพิ่ม ในขณะที่ Windows ต้องติดตั้งWSL2 เพิ่มก่อน นอกจากนี้ชิปApple Silicon ทำให้แบตอยู่ได้จริง 12-18 ชั่วโมง ซึ่งต่างจาก Windows ในระดับราคาเดียวกันอย่างชัดเจน

เหตุผลที่ควรเลือก Windows คือถ้างานต้องใช้โปรแกรมที่รองรับแค่ Windows เช่นโปรแกรมเฉพาะขององค์กร ระบบ ERP บางตัว หรือซอฟต์แวร์เฉพาะทาง การซื้อ Mac แล้วต้องติดตั้ง Windows เพิ่มผ่านParallels จะเสียทั้งเงินและประสิทธิภาพ

น้ำหนัก1.24 กิโล

ดีที่สุดในงบสำหรับ Windows จอ OLED ทำให้อ่านโค้ดและข้อความนานๆ ไม่เมื่อยตา น้ำหนักเบาเทียบเท่า Mac ข้อที่ต้องยอมรับคือแบตสั้นกว่า Mac พอสมควร ถ้าทำงานนอกสถานที่เยอะควรพกสายชาร์จไว้ด้วยเสมอ
Lenovo ThinkBook 14

iv

ตั้งค่าเครื่องใหม่ให้พร้อมทำงานกับ AI

ได้เครื่องมาแล้วมีลำดับที่แนะนำให้ทำก่อนเริ่มใช้งานจริง เพราะถ้าตั้งค่าถูกตั้งแต่แรก จะไม่ต้องแก้ปัญหาทีหลัง

→
สมัคร Claude Pro ($20/เดือน)
นี่คือเหตุผลหลักที่ซื้อเครื่อง ได้ทั้ง Claude.ai และ Claude Code ในราคาเดียว เข้าถึง Claude Code ได้ที่ claude.ai/code ไม่ต้องติดตั้งอะไรเพิ่ม
→
ตั้งค่า Terminal
บน Mac เปิด Terminal แล้วใช้ได้ทันที บน Windows ติดตั้ง WSL2 ผ่าน Microsoft Store แล้วบอก Claude ว่า "ช่วยแนะนำขั้นตอนตั้งค่า WSL2 ทีละขั้น" มันจะอธิบายให้ครบ
→
ติดตั้ง Git
ใช้สำหรับอัปโหลดไฟล์ขึ้นGitHub ผ่าน Terminal แทนการลากไฟล์ทีละครั้ง ตั้งค่าครั้งเดียวใช้ได้ตลอด บน Mac ติดตั้งผ่าน Homebrew บน Windows ดาวน์โหลดจาก git-scm.com
→
สร้าง Notebook แรกใน NotebookLM
ไปที่ notebooklm.google.com สร้าง Notebook สำหรับหัวข้อที่กำลังเรียนรู้อยู่ตอนนี้ เริ่มสะสมเนื้อหาทันที เพราะยิ่งมีข้อมูลมากเท่าไหร่ยิ่งถามได้ลึกขึ้นเท่านั้น
→
ทดลอง Claude Code ครั้งแรก
ลองสั่งอะไรง่ายๆ เช่น "สร้างไฟล์ HTML หน้าสรุปโน้ตส่วนตัว" แล้วดูว่ามันทำอะไรได้บ้าง ไม่ต้องรู้โค้ดก็ทำได้ แค่อธิบายว่าต้องการอะไร

v

บทสรุป: สเปคไม่ใช่คำตอบ วิธีใช้ต่างหากที่สำคัญ

โน้ตบุคที่ดีไม่ได้ทำให้คุณทำงานกับ AI ได้เก่งขึ้น แต่มันขจัดอุปสรรคที่ไม่จำเป็นออกไป ไม่ต้องกังวลว่าแบตจะหมดกลางวัน ไม่ต้องเสียเวลาแก้ปัญหา Terminal ไม่ต้องรอเครื่องช้า

เวลาที่ประหยัดได้จากเครื่องที่ใช่ คือเวลาที่เอาไปใช้กับสิ่งที่สำคัญกว่า

สำหรับคนที่ไม่มีข้อจำกัดเรื่อง Windows เลือก MacBook Air M3 ถ้าต้องใช้ Windows เลือก ASUS Zenbook 14 OLED ถ้างบจำกัดหรืออยากได้เครื่องทนทาน เลือก Lenovo ThinkBook 14

แต่สิ่งที่สำคัญที่สุดคือ เครื่องที่ดีที่สุดในโลก ถ้าเปิดแค่ดูหนังและเลื่อน feed ก็ไม่ต่างอะไรกับเครื่องราคาหมื่นบาทครับ

คลังคำศัพท์ · บทที่ 4

* คำที่ขีดเส้นใต้สีทองในเนื้อหา กดได้เพื่อดูความหมายทันที

Terminal
โปรแกรมที่ให้เราพิมพ์คำสั่งโดยตรงกับระบบปฏิบัติการ แทนการกดปุ่มในหน้าต่าง ใช้รัน Claude Code, Git และเครื่องมือ developer อื่นๆ บน Mac เปิดใช้ได้ทันที บน Windows ต้องติดตั้ง WSL2 ก่อน
ใช้ได้ว่า: "Claude Code ทำงานผ่าน terminal ทำให้สั่งงานได้เร็วและทำหลายขั้นตอนพร้อมกันได้"
WSL2 (Windows Subsystem for Linux)
ระบบที่ทำให้ Windows รัน Terminal แบบ Linux ได้ จำเป็นสำหรับการใช้ Claude Code และ Git บน Windows อย่างเต็มประสิทธิภาพ ติดตั้งครั้งเดียวแล้วใช้ได้ตลอด
ใช้ได้ว่า: "ลง WSL2 แล้ว Windows ใช้ Terminal ได้เหมือน Mac เลย"
Apple Silicon (M-series)
ชิปที่ Apple พัฒนาเอง ใช้สถาปัตยกรรม ARM ที่ประหยัดพลังงานกว่า Intel/AMD ทำให้แบตอยู่ได้นานกว่า และเครื่องไม่ร้อนแม้ใช้งานหนัก เป็นเหตุผลหลักที่ MacBook Air มีแบตยาวกว่าโน้ตบุค Windows ในราคาเดียวกัน
ใช้ได้ว่า: "ที่ MacBook แบตอยู่ได้นานกว่าเพราะ Apple Silicon ไม่ใช่เพราะแบตใหญ่กว่า"
Git
โปรแกรมที่ใช้จัดการและอัปโหลดไฟล์ขึ้น GitHub ผ่าน Terminal แทนการลากไฟล์ด้วยมือ ทำให้อัปเดตเว็บไซต์หรือโปรเจกต์ได้ด้วยคำสั่งไม่กี่บรรทัด
ใช้ได้ว่า: "ใช้ git push ครั้งเดียวแทนการอัปโหลดทีละไฟล์ ประหยัดเวลามาก"
OLED vs IPS
เทคโนโลยีหน้าจอสองแบบ OLED สีสดกว่า ดำลึกกว่า อ่านข้อความสบายตากว่า แต่ราคาสูงกว่า IPS เป็นมาตรฐานทั่วไปที่ใช้งานได้ดี ถ้าอ่านข้อความหรือโค้ดนานๆ OLED คุ้มค่ากับสายตาในระยะยาว
ใช้ได้ว่า: "จ่ายเพิ่มนิดเดียวเพื่อได้จอ OLED คุ้มมากถ้าต้องจ้องหน้าจอทั้งวัน"
