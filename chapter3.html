บทที่ 3

เริ่มต้นทำงานกับ AI อย่างจริงจัง

คู่มือปฏิบัติสำหรับคนที่อยากใช้ Claude, NotebookLM และ AI อื่นๆ ให้เกิดประสิทธิภาพจริง ไม่ใช่แค่ทดลองเล่น

Productivity · เทคโนโลยี  ·  sirichokbook

เริ่มอ่าน

สารบัญ

iปัญหาของคนที่ "ใช้ AI อยู่" แต่ยังไม่เกิดผล iiเลือกเครื่องมือให้ถูกงาน iiiNotebookLM: สมองสำรองที่อ่านแทนคุณ ivClaude: ผู้ช่วยที่คุยรู้เรื่องที่สุด vClaude Code: เมื่อ AI เริ่มทำงานแทนคุณได้จริง viหลักคิดสำหรับอนาคตที่ต้องทำงานกับ AI viiบทสรุป: ทักษะที่แท้จริงในยุคนี้

มีคนจำนวนมากที่บอกว่าตัวเองใช้ AI อยู่แล้ว เปิด ChatGPT ถามคำถามบ้าง ให้มันช่วยแปลอีเมลบ้าง แล้วก็ปิดหน้าต่างไป

แต่ถ้าถามว่าชีวิตการทำงานเปลี่ยนไปมากแค่ไหน คำตอบส่วนใหญ่คือ "ก็ไม่ได้ต่างอะไรมากนัก"

ปัญหาไม่ได้อยู่ที่ AI ไม่ดีพอ แต่อยู่ที่เรายังใช้มันแบบ "ของเล่น" ไม่ใช่ "เครื่องมือ"

บทนี้จะพาคุณผ่านเส้นแบ่งนั้น ตั้งแต่การเลือกเครื่องมือให้ถูกงาน ไปจนถึงการสร้างระบบการทำงานร่วมกับ AI ที่เกิดผลจริงในระยะยาว

· · ·
i

ปัญหาของคนที่ "ใช้ AI อยู่" แต่ยังไม่เกิดผล

ลองนึกถึงครั้งสุดท้ายที่คุณใช้ AI ว่าคุณถามอะไรไป ถ้าคำตอบคือ "ถามเรื่องทั่วๆ ไป" หรือ "ลองดูว่ามันตอบอะไร" นั่นคือสัญญาณว่าคุณยังอยู่ในโหมดทดลอง ไม่ใช่โหมดทำงานจริง

คนที่ได้ประโยชน์จาก AI จริงๆ มักมีลักษณะร่วมกันสามอย่าง หนึ่งคือเขารู้ว่างานชิ้นไหนในชีวิตประจำวันที่เสียเวลาซ้ำๆ สองคือเขามีเครื่องมือเฉพาะสำหรับงานแต่ละประเภท และสามคือเขาสื่อสารกับ AI ได้ชัดเจนเหมือนกับที่เขาจะสื่อสารกับเพื่อนร่วมงานคนหนึ่ง

ที่เหลือล้วนเป็นทักษะที่ฝึกได้ทั้งนั้น

· · ·
ii

เลือกเครื่องมือให้ถูกงาน

ความผิดพลาดที่พบบ่อยที่สุดคือการใช้เครื่องมือเดียวกับทุกอย่าง เหมือนใช้ไขควงตอกตะปู มันพอได้ แต่ไม่ใช่วิธีที่ดีที่สุด ปัจจุบันมีสามเครื่องมือหลักที่คนทำงานทั่วไปใช้แล้วเห็นผลจริง แต่ละตัวเหมาะกับงานคนละประเภท

เครื่องมือ เหมาะกับงานแบบไหน ราคาเริ่มต้น
NotebookLM อ่าน สรุป วิเคราะห์เอกสารที่คุณอัปโหลด ฟรี
Claude / ChatGPT เขียน คิด วิเคราะห์ ระดมไอเดีย ฟรี / มีแบบเสียเงิน
Claude Code สร้างไฟล์ โค้ด งานที่ต้องการผลลัพธ์เป็นไฟล์จริงหลายขั้นตอน ต้องมี Claude Pro ($20/เดือน)

กฎง่ายๆ ที่ใช้ได้เสมอคือ ถ้างานมีเอกสารที่ต้องการให้ AI อ่านและวิเคราะห์ ใช้ NotebookLM ถ้างานต้องการการคิดหรือการเขียน ใช้ Claude ถ้างานต้องการผลลัพธ์เป็นไฟล์หรือมีหลายขั้นตอน ใช้ Claude Code

iii

NotebookLM: สมองสำรองที่อ่านแทนคุณ

NotebookLM ของ Google เป็นเครื่องมือที่เข้าใจง่ายที่สุด หลักการของมันตรงไปตรงมา คุณอัปโหลดเอกสาร มันจะอ่าน สรุป และตอบคำถามจากเนื้อหาในเอกสารนั้น โดยไม่ปะปนกับข้อมูลภายนอก

นั่นคือจุดแข็งที่ทำให้มันต่างจาก AI ทั่วไป เพราะคำตอบมาจากเอกสารของคุณเท่านั้น ไม่ใช่การเดาจากอินเทอร์เน็ต ความเสี่ยงที่จะได้ข้อมูลผิดพลาดจึงต่ำกว่ามาก

1
สร้าง Notebook แยกตามหัวข้อ
อย่าใส่ทุกอย่างในที่เดียว สร้าง Notebook แยกสำหรับแต่ละโปรเจกต์ เช่น "หนังสือที่กำลังอ่าน" หรือ "คลิปที่อยากสรุป" ยิ่ง Notebook เฉพาะเจาะจงเท่าไหร่ คำตอบยิ่งแม่นยำขึ้น
2
อัปโหลดแหล่งข้อมูล
รองรับ PDF, Google Docs, URL เว็บไซต์, YouTube, ไฟล์เสียง และข้อความ วิธีที่ใช้บ่อยคือก๊อปปี้ transcript จาก YouTube แล้ววางลงไป หรืออัปโหลด PDF ของหนังสือที่อยากสรุป
3
ถามแบบเจาะจง ไม่ใช่แบบกว้าง
แทนที่จะถามว่า "สรุปให้หน่อย" ให้ถามว่า "แนวคิดสามอย่างที่นำไปใช้กับการทำงานได้ทันทีคืออะไร" ยิ่งคำถามชัด ยิ่งได้คำตอบที่มีประโยชน์
4
ลอง Audio Overview
ฟีเจอร์ที่น่าสนใจของ NotebookLM คือการแปลงเอกสารเป็นพอดแคสต์สไตล์สองคนสนทนา เหมาะมากสำหรับฟังระหว่างเดินทาง รองรับภาษาไทยและกว่า 50 ภาษา

iv

Claude: ผู้ช่วยที่คุยรู้เรื่องที่สุด

ถ้า NotebookLM คือนักวิเคราะห์ที่ดีที่สุดสำหรับเอกสารของคุณ Claude คือผู้ช่วยคิดที่ดีที่สุดสำหรับงานที่ยังไม่มีเอกสาร มันเหมาะกับงานที่ต้องการการเขียน การคิดวิเคราะห์ หรือการระดมไอเดีย

สิ่งที่ทำให้ Claude ต่างออกไปคือมันอ่านบริบทได้ดีมาก ถ้าคุณบอกให้ชัดว่าคุณเป็นใคร ต้องการอะไร และใช้โทนแบบไหน มันจะปรับตัวให้เหมาะกับคุณทันที

วิธีที่ดีที่สุดในการใช้ Claude คือปฏิบัติกับมันเหมือนน้องใหม่ที่ฉลาดมาก แต่ไม่รู้บริบทอะไรเลย

ตัวอย่างเช่น แทนที่จะพิมพ์ว่า "ช่วยเขียนอีเมลหาลูกค้า" ให้บอกว่า "ฉันเป็น Account Manager ของบริษัท SaaS ลูกค้ารายนี้ใช้ระบบมาสองปีแล้วแต่ยังไม่ได้ต่อสัญญา ช่วยเขียนอีเมลที่ไม่ดูกดดัน แต่ย้ำถึงคุณค่าที่พวกเขาได้รับในช่วงที่ผ่านมา โทนเป็นกันเองแต่ยังเป็นมืออาชีพ" ผลลัพธ์จะต่างกันราวฟ้ากับดิน

อีกสิ่งที่ควรรู้คือ Claude ทำงานได้ดีขึ้นมากเมื่อใช้ฟีเจอร์ Projects ใน Claude.ai เพราะมันจะจำข้อมูลพื้นฐานของคุณไว้ตลอด ไม่ต้องอธิบายใหม่ทุกครั้งที่เริ่มสนทนา

· · ·
v

Claude Code: เมื่อ AI เริ่มทำงานแทนคุณได้จริง

Claude Code เป็นเครื่องมือที่น่าสนใจที่สุดในสามตัว แต่ก็เป็นตัวที่หลายคนยังเข้าใจผิดมากที่สุด เพราะหลายคนคิดว่ามันคือเครื่องมือสำหรับโปรแกรมเมอร์เท่านั้น

แต่ในความเป็นจริง มันคือเครื่องมือสำหรับใครก็ตามที่ต้องการให้ AI ทำงานที่มีผลลัพธ์เป็น "ไฟล์จริง" ไม่ใช่แค่ข้อความในหน้าจอ ผู้จัดการที่ต้องการสร้างรายงาน นักการตลาดที่ต้องการสร้างเว็บเพจ หรือคนที่อยากสร้างเครื่องมือช่วยงานส่วนตัว ล้วนใช้ Claude Code ได้ทั้งนั้น

สิ่งที่ทำให้ Claude Code ต่างจาก Claude ปกติคือมันไม่แค่ตอบ มันลงมือทำ มันอ่านไฟล์ในโฟลเดอร์ของคุณได้ สร้างและแก้ไขไฟล์ได้ และทำงานหลายขั้นตอนต่อเนื่องกันได้โดยอัตโนมัติ

Stripe ใช้ Claude Code กับทีมวิศวกร 1,370 คน และสามารถย้ายโค้ด 10,000 บรรทัดได้ใน 4 วัน จากงานที่ประเมินว่าต้องใช้ 10 คนทำ 1 สัปดาห์

สำหรับคนที่ยังไม่ถนัดด้านเทคนิค จุดเริ่มต้นที่ดีที่สุดคือใช้ Claude Code ผ่านเว็บที่ claude.ai/code ซึ่งไม่ต้องติดตั้งอะไรเลย แค่มี Claude Pro ($20/เดือน) ก็เข้าถึงได้ทันที แล้วลองเริ่มจากงานง่ายๆ ก่อน เช่น "ช่วยสร้างไฟล์ HTML สำหรับหน้าสรุปข้อมูลโปรเจกต์ของฉัน" แล้วค่อยๆ ขยับไปงานที่ซับซ้อนขึ้นเรื่อยๆ

vi

หลักคิดสำหรับอนาคตที่ต้องทำงานกับ AI

เครื่องมือจะเปลี่ยนไปเรื่อยๆ แต่มีหลักคิดบางอย่างที่จะยังคงใช้ได้ไม่ว่าเครื่องมือจะเปลี่ยนไปแค่ไหน

หนึ่ง — บริบทคือทุกอย่าง AI ทำงานได้ดีขึ้นเสมอเมื่อมีข้อมูลมากขึ้น นิสัยที่ดีที่สุดคือการอธิบายสิ่งที่ต้องการให้ครบถ้วนก่อนคาดหวังผลลัพธ์

สอง — ทำซ้ำ อย่าหยุดที่คำตอบแรก คำตอบแรกของ AI มักไม่ใช่คำตอบที่ดีที่สุด การโต้ตอบต่อเนื่อง บอกว่าชอบอะไร ไม่ชอบอะไร และขอให้ปรับ คือวิธีที่ได้ผลลัพธ์ที่ดีที่สุด

สาม — ตรวจสอบเสมอ ไม่ว่า AI จะตอบมาด้วยความมั่นใจแค่ไหน สำหรับข้อมูลสำคัญที่จะนำไปใช้จริง ควรตรวจสอบจากแหล่งอื่นเสมอ

ทักษะที่มีค่าที่สุดในยุคนี้ไม่ใช่การรู้จักเครื่องมือทุกตัว แต่คือการรู้ว่าจะถามอะไร เมื่อไหร่ และกับใคร

สี่ — สร้างระบบ ไม่ใช่แค่นิสัย แทนที่จะคิดว่าจะ "ลอง AI" ในงานชิ้นนั้นชิ้นนี้ ลองมองให้กว้างขึ้นว่างานประเภทไหนที่จะมอบให้ AI ช่วยเป็นประจำ เช่น ทุกครั้งที่ดูคลิปความรู้ก็ส่ง transcript ไปที่ NotebookLM ทุกครั้งที่ต้องเขียนอีเมลสำคัญก็ Draft กับ Claude ก่อน ระบบเล็กๆ เหล่านี้สะสมกันเป็นผลลัพธ์ใหญ่ในระยะยาว

vii

บทสรุป: ทักษะที่แท้จริงในยุคนี้

ในอีกห้าปีข้างหน้า การทำงานร่วมกับ AI จะไม่ใช่ทักษะพิเศษอีกต่อไป มันจะกลายเป็นทักษะพื้นฐานเหมือนกับการใช้ Excel หรือการส่งอีเมล

คนที่เริ่มต้นตอนนี้จะมีข้อได้เปรียบที่ชัดเจนมาก ไม่ใช่เพราะพวกเขาฉลาดกว่า แต่เพราะพวกเขาจะมีเวลาฝึกฝน ทดลอง และสร้างระบบการทำงานของตัวเองมากกว่าคนที่เริ่มทีหลัง

เริ่มต้นเล็ก แต่เริ่มต้นวันนี้

ไม่ต้องเรียนรู้ทุกเครื่องมือพร้อมกัน ไม่ต้องเป็นผู้เชี่ยวชาญ แค่เลือกหนึ่งอย่างที่ตรงกับงานที่คุณทำอยู่มากที่สุด แล้วใช้มันให้จริงจังสักหนึ่งเดือน คุณจะเห็นเองว่ามันเปลี่ยนอะไรได้บ้าง

คลังคำศัพท์ · บทที่ 3
Context Window
ขนาดของ "หน่วยความจำชั่วคราว" ที่ AI ใช้ในการสนทนาหนึ่งครั้ง ยิ่งใหญ่ AI ยิ่งจำบทสนทนาหรือเอกสารที่ยาวได้มากขึ้น Claude มี Context Window ประมาณ 200,000 tokens
ใช้ได้ว่า: "ส่งไฟล์นี้ไป Claude ได้เลย context window มันใหญ่พอ"
RAG (Retrieval-Augmented Generation)
เทคนิคที่ AI ดึงข้อมูลจากแหล่งที่กำหนดไว้ก่อน แล้วค่อยสร้างคำตอบ ทำให้คำตอบอ้างอิงจากข้อมูลจริงแทนที่จะเดาจากความรู้ทั่วไป NotebookLM ใช้วิธีนี้
ใช้ได้ว่า: "NotebookLM ใช้ RAG ทำให้ตอบได้แม่นยำกว่า ChatGPT ปกติสำหรับเอกสารเฉพาะ"
Agentic AI
AI ที่ไม่แค่ตอบคำถาม แต่ลงมือทำงานหลายขั้นตอนได้ด้วยตัวเอง เช่น อ่านไฟล์ สร้างเอกสาร และส่งผลลัพธ์ให้ โดยไม่ต้องให้คนสั่งทีละขั้น Claude Code คือตัวอย่างของ Agentic AI
ใช้ได้ว่า: "Agentic AI คือก้าวถัดไปจาก chatbot ธรรมดา มันทำงานได้โดยไม่ต้องจับมือทุกขั้น"
Workflow Automation
การออกแบบกระบวนการทำงานให้เกิดขึ้นโดยอัตโนมัติหรือกึ่งอัตโนมัติ ในบริบทของ AI คือการสร้างระบบที่ทำให้ AI ช่วยงานซ้ำๆ ได้สม่ำเสมอโดยไม่ต้องเริ่มใหม่ทุกครั้ง
ใช้ได้ว่า: "เราวาง workflow automation ไว้ให้ AI สรุปทุก meeting transcript อัตโนมัติ"
System Prompt
คำสั่งพื้นฐานที่กำหนดให้ AI รู้ว่าควรทำตัวอย่างไร มีบุคลิกแบบไหน และมีข้อจำกัดอะไรบ้างก่อนที่ผู้ใช้จะเริ่มพูดคุย คล้ายกับ briefing ให้พนักงานก่อนเริ่มงาน
ใช้ได้ว่า: "ถ้า Claude ตอบแบบแปลกๆ อาจเป็นเพราะ system prompt ของ operator กำหนดให้ทำแบบนั้น"
